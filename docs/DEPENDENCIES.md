# Dependency maintenance

Workspace manifests, `pnpm-lock.yaml`, and `substreams/Cargo.lock` are authoritative. Node and Rust toolchains are pinned; CI installs with a frozen lockfile. Review upgrades against provider replay, database correctness, and build checks before merging.

## Compatibility exceptions

- TypeScript 6 remains within the installed typescript-eslint supported range. Do not move to TypeScript 7 until the lint stack supports it.
- ESLint 9 is deprecated upstream but retained because the complete Next ESLint plugin set does not accept ESLint 10. This is development tooling, not worker runtime code. Upgrade the compatible plugin set together.
- Substreams JS 0.17 requires protobuf-es 1 and Connect 1. Their explicit peer dependencies are intentional; upgrading them independently to v2 breaks the SDK contract.
- Privy's optional Solana dependencies advertise older TypeScript peer ranges. Scout does not enable Solana monitoring. Webpack also reports an optional Farcaster Solana import and a dynamic import in viem's transitive `ox` package. These third-party diagnostics are not suppressed in the application build configuration.
- ABI code generated by substreams-ethereum triggers four stylistic Clippy lints. Allowances are scoped to the generated module. The SDK-generated WASM wrapper also needs a crate-level raw-pointer lint allowance because the macro emits a separate exported function; Scout's handler accepts owned Rust values.

The install also reports 11 deprecated transitive wallet SDK packages: MetaMask SDK/analytics/communication/install-modal, `@paulmillr/qr`, Safe gateway SDK, and WalletConnect Ethereum/sign-client/universal-provider versions. These enter through the active wallet dependency tree. Replacing their parent SDKs is a separately validated authentication migration; forcing major transitive overrides is not safe cleanup.

## Security patch

`patches/decode-uri-component@0.2.2.patch` backports the bounded UTF-8 decoder from [upstream v0.5.0](https://github.com/SamVerschueren/decode-uri-component/blob/v0.5.0/index.js), preserving the CommonJS export and plus-to-space behavior used by query-string 7. Tests cover malformed input, Unicode, and the CommonJS consumer. Remove this patch when the wallet dependency chain accepts a fixed release directly.

The September 13 audit reports one moderate advisory against that old version despite the backport; no high or critical advisories were reported. This is not a claim of a clean advisory count. Scoped Undici, ws, axios, and uuid overrides remain in `pnpm-workspace.yaml`; review their consumers when changing them.

## Source and license provenance

Scout is MIT licensed. The public Uniswap event ABI is a contract interface, not vendored Solidity implementation. StreamingFast/The Graph supply the reused Substreams infrastructure; exact package and verification references are in [Uniswap integration](UNISWAP-INTEGRATION.md).

[THIRD_PARTY.json](THIRD_PARTY.json) records installed npm package licenses and source URLs. Regenerate it after dependency changes with `pnpm exec tsx scripts/license-report.ts`. It covers the installed platform, not every optional platform binary. Keep upstream license and notice files in distributed dependencies.
